# India Banking Data – Fraud Detection & Financial Data Analysis Dashboard

## 📌 Project Overview

This project analyzes Indian banking transaction data using Microsoft Excel to identify financial patterns, transaction trends, and potential fraud activities.

An interactive Excel dashboard was created to analyze transactions across regions, branches, account types, transaction categories, and payment modes.

## 🎯 Project Objectives

- Analyze banking transaction data
- Identify fraud patterns and suspicious transactions
- Analyze revenue and transaction trends
- Compare transaction performance across regions and branches
- Understand customer transaction behavior
- Create interactive dashboards for better decision-making

## 🧹 Data Cleaning

The banking transaction data was prepared in Excel before analysis.

The cleaning process included:

- Checking for missing values
- Removing unnecessary data
- Correcting data formats
- Standardizing categorical values
- Checking duplicate records
- Preparing data for PivotTables and dashboard analysis

## 📊 Key Insights

The analysis helps identify:

- Regions and branches with higher transaction activity
- Frequently used transaction types
- Popular payment modes
- Fraud patterns across different transaction categories
